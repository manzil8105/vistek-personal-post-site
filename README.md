# My Personal blog site 

A retro, vaporwave themed site I have built to write down my thoughts and write about interesting things that I learn every day. 


## TechStack
* **Framework:** Next.js (App Router)
* **Database:** PostgreSQL (via Supabase)
* **ORM:** Drizzle ORM
* **Styling:** Tailwind CSS
* **Authentication:** `bcrypt` (Hashing) & `jose` (JWT)
